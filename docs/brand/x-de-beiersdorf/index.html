Beiersdorf中文名 · 拜尔斯道夫

它做什么来自德国的美妆与个护品牌，提供美容、护肤或个人护理产品。

Beiersdorf来自创始人Paul C. Beiersdorf的姓氏。名称采用创办者姓名，符合德国传统企业以家族姓氏作为公司名称的方式。

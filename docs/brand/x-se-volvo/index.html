Volvo中文名 · 沃尔沃

它做什么来自瑞典的汽车与出行企业，从事汽车、航空、物流或出行相关业务。

Volvo 名称来自拉丁语“volvo”，意为“我滚动”或“我转动”。1927年瑞典公司采用该名称，象征运动、机械和动力。

命名背景

Volvo 最初由瑞典轴承公司SKF设立汽车品牌，名称来自拉丁语动词。该名称最早注册于SKF，后来用于汽车和工业产品品牌。

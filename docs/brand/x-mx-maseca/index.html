Maseca中文名 · 马塞卡

它做什么来自墨西哥的食品与饮料品牌，生产或经营食品、饮料与餐饮产品。

Maseca是西班牙语“masa seca”的合成缩写，其中masa指玉米面团，seca指干燥，意指干玉米粉。名称直接描述其脱水玉米粉产品属性。

命名背景

Maseca属于墨西哥Gruma公司，是全球知名玉米粉品牌。名称来自产品特征，即经过处理并干燥保存的玉米面粉，与墨西哥玉米食品传统相关。

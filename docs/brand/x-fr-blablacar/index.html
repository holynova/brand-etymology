BLBlaBlaCar 标志

🇫🇷法国 · 互联网与媒体 · 创立年份待补

BlaBlaCar中文名 · 嘀嗒出行/布拉布拉汽车

名称来历BlaBlaCar来自BlaBla与Car组合。BlaBla表示聊天交流，Car表示汽车，名称强调共享乘车中的社交沟通属性。

它做什么来自法国的互联网与媒体品牌，提供在线内容、社交、娱乐或数字平台服务。

命名背景

BlaBlaCar成立于法国，最初名为Covoiturage.fr，后改为BlaBlaCar以适应国际市场。名称来源于用户聊天程度分类功能。

Longines中文名 · 浪琴

它做什么来自瑞士的时尚与奢侈品品牌，经营服饰、运动用品、设计或奢侈品。

Longines 名称来自瑞士索伊米亚地区的一处土地名称“Les Longines”，意为“长长的田地”。创始人奥古斯特·阿加西将工厂建于该地点，并以此作为品牌名称。

命名背景

Longines 于1832年创立于瑞士圣伊米耶地区，创始人与后继经营者将工厂所在地名称用于品牌。该名称保留了当地法语地名传统，与品牌起源地直接相关。

Bandai NamcoBandai Namco

Bandai Namco名称由Bandai与Namco两个公司名称合并形成。Bandai源自日语“万代”，Namco则是原公司名称缩写形式，合并后保留双方品牌识别。

命名背景

Bandai Namco于2005年由万代与南梦宫合并成立。两家公司分别来自玩具、游戏和娱乐产业，合并名称用于延续已有市场认知。

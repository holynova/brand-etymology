Benetton中文名 · 贝纳通

名称来历名称来自创始家族姓氏 Benetton。该品牌由意大利贝内通兄弟创建，直接采用家族名称作为企业与时装品牌名称，属于典型姓氏型品牌命名。

它做什么来自意大利的时尚与奢侈品品牌，经营服饰、运动用品、设计或奢侈品。

Naver 标志

🇰🇷韩国 · 互联网与媒体 · 1999

Naver네이버

Naver 从 navigate（导航）与后缀 -er 的语感出发，塑造一个“在网络中导航的人”。拼写略微改动，使它成为可注册的独立词。

怎么读

/ˈneɪvər/

内-弗

较可信

主要来源一致，但仍缺少一项独立语言或档案证据。

命名背景

韩国门户网站需要表达检索与引路功能，又不想用通用词 Navigator。短化后的 Naver 既像英语词，也保留品牌独占性。

英语派生导航隐喻

命名谱系

英语
navigate

导航、寻找路径

英语后缀

执行动作的人或工具

品牌造词
Naver

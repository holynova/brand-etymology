Acer中文名 · 宏碁

名称来历Acer 来自拉丁语 acer，含义包括敏锐、尖锐。品牌选择该词作为英文名称，表达速度、敏锐和科技创新含义。

它做什么来自中国台湾省的科技与电子企业，提供消费电子、软件或数字技术产品与服务。

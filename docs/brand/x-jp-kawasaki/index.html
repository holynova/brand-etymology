Kawasaki中文名 · 川崎

它做什么来自日本的汽车与出行企业，从事汽车、航空、物流或出行相关业务。

Kawasaki来自创始人川崎正藏的姓氏。该名称直接采用日本姓氏Kawasaki，并非为汽车或摩托车产品创造的新词。

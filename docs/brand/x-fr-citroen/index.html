CitroënCitroën

Citroën来自创始人安德烈·雪铁龙（André Citroën）的姓氏。该姓氏源自荷兰语家族姓氏Smitten或Citroen形式，与柠檬（citroen）一词有关，但汽车品牌采用的是家族名称。

命名背景

安德烈·雪铁龙于1919年创立雪铁龙汽车公司，品牌名称直接继承创始人的姓氏。该姓氏家族来自荷兰，后来在法国发展。关于姓氏最早来源存在语言演变差异。

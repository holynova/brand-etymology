Grab中文名 · Grab

它做什么覆盖出行、外卖、支付与金融服务的平台。

Grab 来源于英语单词 grab，意为抓取、拿取。名称表达快速获得服务的概念，与打车和移动服务平台定位相关。

命名背景

Grab 于2012年在马来西亚成立，后迁至新加坡。最初品牌 GrabTaxi，随后扩展至配送、支付等业务并简称为 Grab。

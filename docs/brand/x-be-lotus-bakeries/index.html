Lotus Bakeries中文名 · 莲花烘焙

名称来历Lotus Bakeries中的Lotus取自莲花意象，象征纯净和自然；Bakeries表示烘焙企业，组合形成品牌名。

它做什么来自比利时的食品与饮料品牌，生产或经营食品、饮料与餐饮产品。

命名背景

比利时Lotus Bakeries创立于1932年，以焦糖饼干Biscoff闻名。名称来自产品企业定位，而非创始人姓氏。

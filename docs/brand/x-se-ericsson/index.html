名称来历Ericsson 名称来自创始人Lars Magnus Ericsson的姓氏。瑞典语姓氏形式中的“-son”表示“某人的儿子”，属于北欧传统父名姓氏。

它做什么来自瑞典的科技与电子企业，提供消费电子、软件或数字技术产品与服务。

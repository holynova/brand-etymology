🇩🇰丹麦 · 工业与能源 · 创立年份待补

DSV中文名 · 迪艾斯维

它做什么来自丹麦的工业与能源企业，从事制造、基础设施、能源或工业技术业务。

DSV是丹麦语名称De Sammensluttede Vognmænd的缩写，意为联合运输商，来源于公司成立时期由多个运输企业组成的背景。

命名背景

DSV成立于丹麦，最初是一家运输合作组织。随着国际物流业务扩展，公司保留DSV缩写作为全球品牌名称，不再强调原始丹麦语全称。

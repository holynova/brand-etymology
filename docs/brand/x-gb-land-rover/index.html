Land Rover中文名 · 路虎

它做什么来自英国的汽车与出行企业，从事汽车、航空、物流或出行相关业务。

Land Rover由两个英语普通词组成：Land表示土地、陆地，Rover表示漫游者、探险者。名称用于表达车辆适应复杂地形、进行越野探索的产品定位。

命名背景

Land Rover最初是英国Rover公司在1948年推出的越野车型名称，后来发展为独立汽车品牌。名称强调车辆在乡村、荒野等环境中的移动能力。

Orange 标志

🇫🇷法国 · 通信 · 1994

OrangeOrange

Orange 原是英国移动网络品牌，以日常颜色词摆脱电信行业的技术缩写。法国电信收购后逐步把 Orange 变成整个集团名称。

命名背景

一个无国界、可视化强的颜色词，比 France Télécom 更适合国际消费品牌。名称迁移记录了品牌价值反向覆盖母公司的过程。

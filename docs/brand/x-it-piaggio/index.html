Piaggio中文名 · 比亚乔

它做什么来自意大利的汽车与出行企业，从事汽车、航空、物流或出行相关业务。

Piaggio 名称来自创始人家族姓氏 Piaggio。该姓氏成为企业名称，代表创始人里纳尔多·皮亚乔建立的工业企业传统。

命名背景

Piaggio 于1884年由里纳尔多·皮亚乔创立，早期制造船舶和航空产品，后来因 Vespa 踏板车闻名。品牌名称保持家族姓氏。

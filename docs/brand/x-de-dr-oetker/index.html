Dr. Oetker中文名 · 奥特克博士

它做什么来自德国的食品与饮料品牌，生产或经营食品、饮料与餐饮产品。

Dr. Oetker来自创始人August Oetker的姓氏，其中Dr.表示其博士身份。品牌名称结合个人头衔和姓氏，形成企业标识。

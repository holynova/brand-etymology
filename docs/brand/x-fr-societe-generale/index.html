Société GénéraleSociété Générale

Société Générale意为“普通公司”或“综合公司”。名称来自1864年法国成立银行时使用的正式法语机构名称，并非个人姓名。

命名背景

Société Générale成立于1864年，是法国历史悠久银行之一。名称体现19世纪法国企业命名习惯，强调综合金融服务性质。

Hermès 标志

🇫🇷法国 · 时尚与奢侈品 · 1837

HermèsHermès

Hermès 名称来自创始人 Thierry Hermès 的姓氏。该姓氏成为法国奢侈品牌名称，与希腊神话人物 Hermes 并非品牌命名直接来源。

命名背景

Hermès 于1837年由 Thierry Hermès 在巴黎创立，最初生产马具用品，后发展为皮具和奢侈品品牌。名称保留创始人家族姓氏。

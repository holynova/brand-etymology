Breitling中文名 · 百年灵

它做什么来自瑞士的时尚与奢侈品品牌，经营服饰、运动用品、设计或奢侈品。

Breitling 名称来自创始人Leon Breitling的姓氏。该姓氏成为1884年创立的瑞士钟表公司的品牌名称，属于典型创始人姓氏命名。

命名背景

Leon Breitling 于1884年在瑞士圣伊米耶创办工作室，后来品牌专注计时工具和航空表领域。名称直接继承创始家族姓氏，没有公开证据显示有其他寓意。

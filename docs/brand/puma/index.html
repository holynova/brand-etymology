PUMA 标志

🇩🇪德国 · 时尚与奢侈品 · 1948

PUMA中文名 · 彪马

它做什么来自德国的时尚与奢侈品品牌，经营服饰、运动用品、设计或奢侈品。

PUMA 名称来自英语和德语中对美洲狮的称呼 Puma。创始人鲁道夫·达斯勒选择该动物名称，表达速度、力量和敏捷形象。

命名背景

鲁道夫·达斯勒于1948年创立 Puma。品牌名称不同于 Adidas 的姓名缩合方式，而采用动物名称作为品牌象征。

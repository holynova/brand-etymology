Suntory中文名 · 三得利

它做什么来自日本的食品与饮料品牌，生产或经营食品、饮料与餐饮产品。

Suntory名称来自创始人鸟井信治郎早期品牌“Sun”和其姓氏Torii的组合。Sun源自英文“太阳”，Torii对应鸟井姓氏罗马字拼写，后来形成Suntory这一公司名称。

命名背景

三得利创立于日本大阪，创始人为鸟井信治郎。早期以威士忌和葡萄酒业务发展，品牌名称结合西方语言元素与创始人姓氏，体现日本企业早期国际化命名方式。

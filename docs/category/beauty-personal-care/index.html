KR.008较可信
Amorepacific 标志

Amorepacific中文名 · 爱茉莉太平洋

它做什么

来自韩国的美妆与个护品牌，提供美容、护肤或个人护理产品。

名称来历

Amorepacific由Amore和Pacific组成，Amore来自意大利语“爱”，Pacific表示太平洋，名称表达东方美与国际市场连接的理念。

BEBeiersdorf 标志

Beiersdorf中文名 · 拜尔斯道夫

它做什么

来自德国的美妆与个护品牌，提供美容、护肤或个人护理产品。

名称来历

Beiersdorf来自创始人Paul C. Beiersdorf的姓氏。名称采用创办者姓名，符合德国传统企业以家族姓氏作为公司名称的方式。

L'Oréal 标志

L'Oréal中文名 · 欧莱雅

它做什么

护肤、彩妆与个人护理集团。

名称来历

L'Oréal 名称来源于法语词 l'auréale，意为类似金色光环、荣耀之意。该名称由创始人 Eugène Schueller 选择作为化妆品品牌名。

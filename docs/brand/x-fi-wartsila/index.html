WärtsiläWärtsilä

Wärtsilä来自芬兰东部北卡累利阿地区的瓦锡拉村名，公司最初在该地建立工厂，因此采用所在地名称作为企业名称。

命名背景

Wärtsilä成立于芬兰，早期经营钢铁和机械制造，后来发展为船舶动力和能源技术企业。品牌名称保留创立地点的地名来源。

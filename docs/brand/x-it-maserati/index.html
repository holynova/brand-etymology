MaseratiMaserati

Maserati 名称来自创始人阿尔菲耶里·玛莎拉蒂及其兄弟的姓氏 Maserati。该姓氏成为公司品牌名称，代表创始家族与意大利机械制造传统。

命名背景

Maserati 于1914年由玛莎拉蒂兄弟在博洛尼亚创立，早期从事赛车和汽车制造。品牌名称直接沿用家族姓氏，没有发现更早的词源创造记录。

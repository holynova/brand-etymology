PUMA 标志

🇩🇪德国 · 时尚与奢侈品 · 1948

PUMAPUMA

Rudolf Dassler 最初把名字与姓氏缩成 Ruda，很快改为 PUMA。美洲狮的速度、弹跳和力量更适合运动鞋，也比创始人缩写更有画面。

命名背景

Dassler 兄弟分家后分别创立 Puma 与 Adidas。一个选择动物意象，一个选择姓名拼合，两种命名至今隔河相望。

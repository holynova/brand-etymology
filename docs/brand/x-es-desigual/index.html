Desigual中文名 · 德西瓜尔

它做什么来自西班牙的时尚与奢侈品品牌，经营服饰、运动用品、设计或奢侈品。

Desigual来自西班牙语单词desigual，意为“不一样的、不平等的”。品牌直接采用描述性词汇表达其反传统、强调差异化设计的理念。

🇨🇭瑞士 · 时尚与奢侈品 · 创立年份待补

Omega中文名 · 欧米茄

它做什么来自瑞士的时尚与奢侈品品牌，经营服饰、运动用品、设计或奢侈品。

Omega 名称来自希腊字母 Omega（Ω），表示终结、完成或最高阶段。1894年品牌采用该名称，象征其机芯设计达到成熟和完善阶段。

命名背景

Omega 原为瑞士拉绍德封地区公司的机芯名称，1894年推出Omega机芯后，公司逐渐以该名称作为品牌。名称借用了希腊字母文化含义。

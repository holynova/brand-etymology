Microsoft 标志

🇺🇸美国 · 科技与电子 · 1975

Microsoft中文名 · 微软

它做什么软件、云计算与办公生产力服务公司。

Microsoft由microcomputer（微型计算机）和software（软件）两个英文词组合而成。名称直接描述公司早期开发微型计算机软件的业务方向。

命名背景

微软由比尔·盖茨和保罗·艾伦创立。公司成立初期主要开发Altair计算机的软件，因此名称反映了当时个人计算机和软件产业的发展趋势。

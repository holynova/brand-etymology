JYP Entertainment中文名 · JYP娱乐

它做什么来自韩国的互联网与媒体品牌，提供在线内容、社交、娱乐或数字平台服务。

JYP 来自创始人朴振英（Park Jin-young）的英文姓名缩写。品牌以个人姓名首字母作为核心标识，后加入 Entertainment 表示音乐娱乐公司性质。

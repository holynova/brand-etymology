Hepsiburada中文名 · 赫普西布拉达

名称来历Hepsiburada 来自土耳其语 hepsi（土耳其语意为全部）和 burada（这里），组合意为“这里有全部”。名称强调电商商品丰富。

它做什么来自土耳其的科技与电子企业，提供消费电子、软件或数字技术产品与服务。

Renault 标志

🇫🇷法国 · 汽车与出行 · 1898

RenaultRenault

Renault 是 Louis、Marcel 与 Fernand Renault 三兄弟的姓氏。早期公司名 Renault Frères 直译就是“雷诺兄弟”。

命名背景

姓氏把工程发明与家族经营连在一起。公司后来国有化再私有化，家族已退出，名称仍保留工业起点。

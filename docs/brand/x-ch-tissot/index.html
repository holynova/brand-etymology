Tissot中文名 · 天梭

它做什么来自瑞士的时尚与奢侈品品牌，经营服饰、运动用品、设计或奢侈品。

Tissot 来源于创始人 Charles-Félicien Tissot 家族姓氏。品牌沿用法语姓氏作为名称，符合瑞士传统制表企业命名方式。

命名背景

Tissot 于瑞士勒洛克创立，最初由 Tissot 家族经营制表业务。名称一直保留家族身份，并成为瑞士大众高级腕表品牌之一。

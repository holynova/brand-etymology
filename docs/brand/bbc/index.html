BBC 标志

🇬🇧英国 · 互联网与媒体 · 1922

BBCBBC

BBC 是 British Broadcasting Corporation 的首字母。1922 年先叫 British Broadcasting Company，1927 年改制为 Corporation，缩写却保持不变。

怎么读

/ˌbiː biː ˈsiː/

B-B-C

已确认

核心命名说法由品牌资料明确支持。

命名背景

同一组三字母跨过商业公司到公共机构的制度变化。名称看似稳定，最后一个 C 背后的词却记录了治理身份改变。

首字母公共机构名

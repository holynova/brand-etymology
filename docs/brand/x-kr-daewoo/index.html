Daewoo中文名 · 大宇

名称来历Daewoo来自韩语“大宇”（대우），意为“大”的宇宙或宏大的世界。该名称表达企业追求广阔发展空间的愿景，由创始人金宇中的公司命名。

它做什么来自韩国的工业与能源企业，从事制造、基础设施、能源或工业技术业务。

命名背景

Daewoo成立于1967年，最初名称为大宇实业（Daewoo Industrial）。名称中的“大宇”是汉字词，在韩国企业命名中体现规模、远景和国际化扩张理念。

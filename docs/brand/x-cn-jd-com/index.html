它做什么来自中国的互联网与媒体品牌，提供在线内容、社交、娱乐或数字平台服务。

JD.com 的名称来自中文企业名“京东”，英文品牌采用 JD 作为缩写。京代表北京，东来自创始人刘强东姓名中的“东”，组合形成公司名称。

命名背景

京东最初由刘强东创立，早期名称为“京东多媒体”，主营光磁产品，后发展为综合电商平台。英文 JD 是对中文名称的国际化简写，并非独立造词。

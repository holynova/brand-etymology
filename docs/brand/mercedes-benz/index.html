Mercedes-Benz 标志

🇩🇪德国 · 汽车与出行 · 1926

Mercedes-Benz中文名 · 梅赛德斯-奔驰

名称来历Mercedes-Benz 由 Mercedes 与 Benz 组成。Mercedes 来自早期车型名称，源于经销商埃米尔·耶利内克女儿 Mercedes Jellinek 的名字；Benz 来自卡尔·本茨姓氏。

它做什么豪华乘用车与商用车品牌。

命名背景

奔驰品牌历史由 Benz 与 Daimler 体系发展而来，Mercedes 名称在1901年前后用于戴姆勒汽车。1926年合并后形成 Mercedes-Benz 品牌名称。

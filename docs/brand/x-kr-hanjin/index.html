Hanjin中文名 · 韩进

名称来历Hanjin 来自韩语“한진（韓進）”，通常解释为“韩国前进”或“韩国产业进步”。名称采用韩国企业常见汉字词组合。

它做什么来自韩国的汽车与出行企业，从事汽车、航空、物流或出行相关业务。

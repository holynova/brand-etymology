Itaú中文名 · 伊陶

名称来历Itaú来自巴西图皮语“itaúba/itaú”等词根体系，与“石头、黑色石块”相关。该名称被银行采用，用于体现巴西本土文化元素和稳固可靠的品牌形象。

它做什么来自巴西的金融机构，提供银行、支付、保险或投资服务。

命名背景

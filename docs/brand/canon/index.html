Canon 标志

🇯🇵日本 · 科技与电子 · 1937

Canonキヤノン

最早的相机原型叫 Kwanon，来自佛教的观音菩萨。为进入国际市场，公司改成近音的 Canon，同时借用英语 canon“准则、经典”的正面含义。

怎么读

/ˈkænən/

已确认

核心命名说法由品牌资料明确支持。

命名背景

从宗教文化名到国际商标的改写，既保留声音记忆，又获得可注册、可解释的英语形式，是跨文化命名的经典案例。

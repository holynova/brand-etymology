Bayer中文名 · 拜耳

它做什么来自德国的工业与能源企业，从事制造、基础设施、能源或工业技术业务。

Bayer 名称来自创始人弗里德里希·拜耳（Friedrich Bayer）的姓氏。公司1863年成立时即采用创办家族姓氏作为企业名称，后来成为德国化工与制药领域的重要品牌。

命名背景

拜耳公司由Friedrich Bayer与Johann Friedrich Weskott共同创立，最初生产合成染料。Bayer这一名称属于典型德国工业企业家族姓氏命名，与创始人的个人身份直接相关。

Dior中文名 · 迪奥

它做什么来自法国的时尚与奢侈品品牌，经营服饰、运动用品、设计或奢侈品。

Dior来自创始人克里斯蒂安·迪奥（Christian Dior）的姓氏。该名称不是描述性词汇，而是以创始人的家族姓氏作为时装屋品牌名称。

命名背景

Christian Dior于1946年在法国创立同名高级时装屋，品牌名称直接关联创始人身份和法国高级时装历史。公开资料普遍将Dior解释为创始人姓氏来源。

UniCredit中文名 · 裕信银行

它做什么来自意大利的金融机构，提供银行、支付、保险或投资服务。

UniCredit 是由 Uni（统一、联合）与 Credit（信用）组成的现代商业名称，用于表达统一金融服务和信贷业务。

命名背景

UniCredit 于1998年由意大利银行集团重组形成。名称采用国际化英语形式，区别于传统银行姓氏或地名命名。

Microsoft 标志

🇺🇸美国 · 科技与电子 · 1975

MicrosoftMicrosoft

Microsoft 把 microcomputer 与 software 拼合，最早还写作 Micro-Soft。中文“微软”则把 micro 的“微”和 software 的“软”直接组合。

怎么读

/ˈmaɪkrəsɒft/

迈-克柔-索夫特

已确认

核心命名说法由品牌资料明确支持。

命名背景

1970 年代微型计算机刚形成市场，名字像一句精确业务定义。随着软件成为基础设施，这个描述词逐渐变成专有名。

Philips中文名 · 飞利浦

它做什么健康科技、医疗设备与个人健康产品公司。

名称来自创始人之一弗雷德里克·菲利普斯的姓氏。1891年荷兰菲利普斯父子创办公司时，以家族姓氏作为企业名称，后来成为电子品牌。

命名背景

Philips 最初是荷兰埃因霍温成立的电灯制造企业，名称直接关联创始家族。公司业务后扩展至消费电子、医疗设备和照明等领域。

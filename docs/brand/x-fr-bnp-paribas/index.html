BNP Paribas中文名 · 法国巴黎银行

名称来历BNP Paribas由两个金融机构名称合并而来：Banque Nationale de Paris（巴黎国民银行）与Paribas（巴黎荷兰银行旧称）。名称体现企业合并历史。

它做什么来自法国的金融机构，提供银行、支付、保险或投资服务。

BNP Paribas于2000年由BNP收购Paribas后形成。品牌名称保留两个历史金融品牌元素，代表法国大型银行集团。

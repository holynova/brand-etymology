Nutella 是 Ferrero 创造的品牌名称，由英语 nut（坚果）与意大利语常见后缀 -ella 组合形成，用于表达榛果可可酱产品特征。

命名背景

该名称于1960年代用于 Ferrero 榛果可可产品。它不是传统词汇，而是人工创造的商业名称，通过坚果联想和柔和后缀塑造亲和感。
